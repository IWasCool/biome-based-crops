# Biome Based Crops

Source code for a Minecraft mod that makes crops and trees grow according to biome climate.
Includes configurable growth restrictions and optional Farmer's Delight, Biomes O' Plenty, and Tough As Nails support.

Targets Minecraft 1.21.1, NeoForge 21.1.251+, and Java 21.

The code is available to view, reuse, modify, and port under the [MIT license](LICENSE).
