# Changelog

## 1.0.0 (in development)

- Added nearby heating from fire, lit campfires, lava, and magma, and cooling from ice and snow.
- Added Greenhouse Cores that emulate sampled biomes when enclosure, glass, native material, and climate requirements are met.
- Added a Greenhouse Probe for biome sampling and checking crop conditions.
- Added an English Farmer's Field Guide with Minecraft book artwork, ruled pages, a searchable biome index, and visual setup pages for each biome.
- Added labeled material icons, climate indicators, a greenhouse cutaway, and crafting grids, with bold ink headings and no hover popups.
- Added survival crafting recipes and configurable greenhouse materials, range, and temperature sources.
- Added per-crop and per-sapling biome overrides using biome IDs, biome tags, or `*` for every biome.
- Applied biome overrides to natural growth, bonemeal, supported fertilizers, and item tooltips.
- Preserved configurable climate defaults, category switches, operator commands, and optional integrations.
- Added biome-rule regression tests, configuration examples, and GitHub release builds.
- Removed unused template examples and internal pack audit documents.
